# 📐 수학몬스터 오일러 (Mathmon Euler)

> **중학교 1학년 2학기 수학 교육용 레트로 픽셀 RPG & 실시간 1:1 PVP 대전 웹게임**  
> 100% 자체 제작 오리지널 그래픽·사운드·스토리·데이터셋 (비영리 교육용)

---

## 🌟 게임 소개
오일러 박사님의 연구실에서 스타팅 수학몬을 선택하고, 기본도형부터 통계까지 중1 2학기 전 단원의 수학 문제를 풀며 배틀하는 교육용 레트로 RPG입니다.  
친구들과 방 코드를 공유하여 실시간으로 1:1 두뇌 배틀을 즐길 수 있습니다.

### 📚 학습 단원 (중1 수학 2학기)
1. **Ⅰ. 기본 도형**: 점·선·면·각, 맞꼭지각, 동위각과 엇각, 평행선의 성질, 위치 관계
2. **Ⅱ. 작도와 합동**: 삼각형의 작도 조건, 삼각형의 합동 조건 (SSS, SAS, ASA)
3. **Ⅲ. 평면도형**: 다각형의 대각선 개수, 내각·외각의 합, 원과 부채꼴(호의 길이, 부채꼴 넓이)
4. **Ⅳ. 입체도형**: 다면체(오일러 공식 $v - e + f = 2$), 정다면체(5가지), 회전체, 겉넓이와 부피
5. **Ⅴ. 통계**: 줄기와 잎 그림, 도수분포표, 히스토그램과 도수분포다각형, 상대도수

### 👾 등장 수학몬
- **각도롱 → 부채도롱 → 호도룡** (평면/곡선 계열)
- **다면호 → 정다면호 → 오일러타이거** (다면체/입체 계열)
- **원뿔범 → 회전바다사자 → 구해왕** (회전체/구 계열)
- 야생 수학몬: **맞꼭지새, 평행냥, 작도개구리, 히스토북이**

- **Graphics & Audio**: HTML5 Canvas 2D Pixel Art Generator, Web Audio API 8-bit Chiptuner
- **Deployment**: Vercel
